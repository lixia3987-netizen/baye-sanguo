HD开场在实际LIB载入之后、进入原生主循环之前准备七张图片，最多等5秒；经典模式直接启动，未知库、缺图和超时仍进入原生游戏。预加载不读取原生全局或发送按键，实际开始后仍需原生事件、资源和显示戳授权。图片缓存按完整资源元数据、manifest代次和实际LIB代次绑定，迟到回调只能重绘当前原生显示，不能复活旧事件。
