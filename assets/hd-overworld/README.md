# HD Overworld 素材包

- 用途：`feature/hd-graphics` 大地图表现层，**默认不合入 main**。
- **地形**（`terrain/*.png`）：Wikimedia Jian'an Commanderies 裁切衍生（CC BY-SA 4.0，见 `reference/LICENSE.txt`）。1920×1080 RGBA。
- **城标位置**：`jianan-cities.json` 史实 UV，不是引擎 12×8 格。
- 城标 / 路笔刷等其它层仍是 AI 占位，不是步步高原作美术。
- 清单对齐 `docs/hd-overworld-spec.md` §10。
