# HD Overworld 素材包

- 用途：`feature/hd-graphics` 大地图表现层，**默认不合入 main**。
- **地形**（`terrain/base_plains.jpg`）：Wikimedia China LCC topographic 全图（无国界，CC BY-SA 4.0，见 `reference/LICENSE.txt`）。3840×3309，含海南 / 南海。视口 1920×1080 可拖动。
- **城标位置**：`china-lcc-cities.json` 地图坐标，绘制时减摄像机偏移。
- 城标 / 路笔刷等其它层仍是 AI 占位，不是步步高原作美术。
- 清单对齐 `docs/hd-overworld-spec.md` §10。
