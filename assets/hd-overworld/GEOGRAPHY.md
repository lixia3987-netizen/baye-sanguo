# 大地图地理对齐说明（史实向）

城标位置仍由引擎 `g_CityPositions` 决定（约 12×8 格），**不挪城**。
地形/河流/山脉按「西左北上」与城点相对关系重绘：

| 要素 | 布局意图 |
|------|----------|
| 黄河 | 偏北横贯（西→东再偏东北），对应关中/中原以北 |
| 长江 | 偏南横贯（西→东入江东），对应巴蜀→荆襄→江东 |
| 淮河 | 长江以北、偏东的辅助水系 |
| 祁连/西域山地 | 左侧（凉州方向） |
| 秦岭 | 中部东西向分隔线（关中与汉中/巴蜀之间） |
| 太行 | 中北部偏东的南北向 |
| 南岭 | 南部横带 |
| 森林 | 南/西南更密（巴蜀缘、荆楚、岭南） |

锚点示意（引擎格，非精确经纬度）：西凉(1,0) 安定(2,1) 天水(3,2) 晋阳(5,1) 等。
词典原版格子地图是抽象战略图，无法与真实经纬度 1:1；本层目标是「看起来像中国山河，并与城点相对方位一致」。
