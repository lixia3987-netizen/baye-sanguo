## 本轮修复

战场按钮在document捕获阶段消费pointerup，而系统宿主已记录相应pointerdown，导致指针4／5／6长期残留、系统入口保持blocked。将系统的四种pointer事件监听移至window捕获阶段，使其收到完整配对；无关控件仍不能授权系统输入，双指、按住、旧票据和隐藏边界保护保持。安装后的三局均验证战场退出后指针清空，两次系统打开各只发送一次原生EXIT。

专项302项通过；旧产品源码在新增6个事件传播用例中全部失败，证明回归用例能暴露旧缺陷。手机入口同步更新脚本缓存版本。

两次中间运行已完成真实保存、宴请、结束和刷新，但验证工具在尚未LOAD的标题阶段读取fullworld，因人物数为零而失败。本轮增加专用预加载采样，仅接受原版TITLE或LOAD的当前所有者、完整票据双读和无竞争窗口，明确标记`worldSampled:false`；活动MAP／CITY不能走此入口。实际LOAD后仍读取完整已采世界并严格比较，未放宽恢复判定。新增12个正反用例，继任验算模块共83项通过。

继任仍使用原生CAMPAIGN context5／kind1直接零基人物ID及完整名单、packedNames、data引用和代次核对。同步完成通知只读取证，不改变业务、输入、随机数或归属。本批没有原生源码修改，也没有新native build。
