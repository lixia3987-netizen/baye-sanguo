# 原版移动横屏战场限定实战验证

2026-10-11，接续 `40aa10a` 的原生归属、技能列表与 LCD 首键修复，完成原版移动战场的首批限定真实浏览器验证。完整移动 HD 继续为 partial。本批只改验证工具、测试与记录，没有修改游戏规则、原生四件或新增 native build。结构化结果、完整压缩原始报告、执行工具与选存截图见[验证摘要](m5-mobile-battle-20261011.json)。

独立私有 Chrome 从原版第一时期马腾开局，通过天水8的真实出征进入敌方河内9。出征向导使用公开原生 LCD 输入，不能算作 HD MARCH 全触控验收。实际所选零基人物 ID 为 `5,58,60,61,62,63,65,66`；没有改人物、兵粮、随机数或胜负。

出征校验读取已认证原版 LIB 的实际城位、道路及费用，精确核对新增 Order27、槽170、编队槽0及十个 LE U16 编队项 `6,59,61,62,63,64,66,67,0,0`。天水粮草505→0、金钱237→237；完整200人、38城、2000队列、200订单的已采字段、600编队字节与30槽标志只允许原生出征变化。订单未采集的 Arms／Money／Consume 字段不作完整结构逐字节声明。

最终战场局通过15个截图阶段、32项检查和13个行动记录，范围如下：

- 844×390、667×375 的实际 HD 战场；格子与操作按钮至少44 CSS像素。拖动浏览、经典回切再恢复不会发送游戏按键或改变兵粮。
- 当前人物选择、真实移动范围、合法移动、MOVE取消及ACTION回滚。取消手势、多指、按住后旋转，以及真实隐藏私有标签页后恢复均退休旧操作。
- 马腾真实“谍报／践踏”菜单可见并可取消。此项只证明名单与输入，不证明施法、扣MP或计谋成功。
- ACTION“查看”进入原生 HELP LCD；LCD中心DOWN即退休HELP，随后UP不操作新ACTION。可信物理搜索键只发送一个原生SEARCH，VIEW通过LCD中心DOWN／UP返回PICK；双方单位与粮草不变。
- 马腾待机只令 `active:0→1`。实际原生MP上限为41，当前MP41保持；全世界已采字段、其它单位、兵力与粮草不变。低于上限时加1仅有独立算术回归覆盖，不能称实际恢复MP已验。
- SYSTEM、退兵确认取消和三个设置打开／取消保持当前设置、单位与粮草。一次显式全军结束使bout1→2并回到下一玩家PICK，证明经过原生AI控制流；没有据此声称AI攻击或伤害通过。

实际输入观测器在游戏监听器之前注册，最终记录5次可信战场pointerdown和4次原生LCD触摸事件。先前第四局跑到下一回合，但晚注册观测器被游戏的事件拦截挡住，最终断言失败；该局仍保留失败，不冒充整体通过。第五局工具修正后通过，第六局增加独立出征／待机精确校验后再次完整通过。此前技能菜单失败原件也继续保留。
