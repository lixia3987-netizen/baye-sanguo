# 原版移动战场接入检查点

2026-10-11，按“当前已修改的内容提交并推送”保存本轮进展。本批为移动横屏战场的初步接入，完整移动 HD 仍为 partial，尚未完成移动战场实战验收。

`m.html` 新增独立战场布局，复用原版战场规则、地形、范围反馈及逐键回执；移动视角使用至少 44 CSS 像素的格子，并通过拖动浏览地图。系统、取消、菜单与经典回切使用当前原生输入票据。移动战场模式独立保存，不覆盖 PC 偏好。报告、帮助、形势图、动画等未接入画面交还真实 LCD。

输入同时核对原版 LIB 身份、当前数据对象、输入序列、将领队列、单位状态、菜单和当前移动／目标范围。拖动、多指、取消、尺寸变化、隐藏及失焦会退休旧操作；最终发键再次核对当前归属。原生数据保持不透明引用，不序列化整个数据对象。HP／MP 按原生 U16 读取，移动力按 U8 读取。

检查中修复了经典模式切回 HD 的入口、共享最小票据缺少 native 字段导致的拖动异常、LCD 展示被 HD 覆盖及数据重绑后的视角问题；页面滚动仅对当前 HD 战场侧栏放行。

新增两组自动化测试覆盖共享命令归属及移动原生读取／手势夹具，分别 34 项及 91 项通过。Windows 全量 66 模块、1936/1936 项通过，零失败／跳过，使用仓库 clang 与 4 并发。正式结果见本地 `build/mobile-battle-checkpoint-tests-20261011.log`，该日志不作为可移植实战归档。复跑使用 `npm run test:mobile-battle`。

本批没有运行新的浏览器战斗、真实触摸或 Android／iOS 真机验证，没有修改原生引擎或 WASM。后续需要实际出征进入战场，验证移动、攻击、计谋、系统菜单、LCD 交还与战斗结束，以及两种横屏尺寸、后台恢复和真机性能。此前人物立绘、城池与地图的记录继续保留各自原有范围，不能替代本批战场验收。
