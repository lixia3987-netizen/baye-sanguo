读取器对同一原生菜单、输入序号、行动者、世代、ID／名称字节及数据引用三次采样；来源漂移、重入或自定义技能列表／名称时撤回增强信息，保留原技能按钮。规则字段及系数先读取到局部值再校验，避免重复 getter 返回未经校验的值。绘制与读取无原生发键或世界写入，无 C／WASM 改动。
