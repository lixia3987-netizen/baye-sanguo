# 地形帮助 HD 信息卡（V83，轻量开发验证）

2026-10-26，PC／手机战场地形帮助整理为信息卡：地形类别标题、装饰符号、捕获位置和原说明。此前已能完整显示原说明，本批改进信息层次，不增加原生内容、行动或输入。

标题直接对应编译引擎发布的 terrain 类别 0..7：草地／平原／山地／森林／村庄／城池／营寨／河流；不是原始 tile 分类。位置保留当前 HELP 发布时的零基 x/y，不读取后来焦点。说明仍取当前库的完整原文，沿用原有竖线换行，其余空白、特殊符号及文字保持；不硬编码或推算防御、移动与计谋效果。自定义覆盖、未知类别、不完整或过期发布继续沿原 LCD／正文回退。

仅现有有效完整 kind2 进入新渲染器，原 nativeHelpDetail DTO、HELP 输入归属、菜单与返回票保持。缓存包含视图 epoch、完整详情及正文，并核对首节点；旧卡被回退内容替换后可重建，切换人物或无效帮助会清理地形节点。没有新增外部 API／地图 getter 回调；人物头像及独立移动详情链保持。

两个相关模块最终新跑 **343/343**，净新增 3 组，失败／取消／跳过／todo 均 0，17 件所选来源保持。覆盖八种类别、字段边界、特殊文字与空白保真、缓存／正文更新／清理、单位互换、移动空地归属及过期票退休；读取与绘制零原生键／零世界写入，显式返回另核一次。旧地形正文用例仍核同一原字符串，只将断言目标移到新增标题下的说明节点。未做 C 编译或全量回归。

PC／手机各一次最终受控布局检查通过，采用实际生产 renderer 与模拟发布／长文本，说明区可滚动，返回按钮保持可见。首轮 PC 面板边缘超出窗口，保留原 false 后仅为地形卡面板采用 border-box 修正。DOM 初始测量为 1264×625／651×280，PNG 输出为 1280×720／667×375，分别记录；两轮四次自有 Chrome 均退出。另保留一次测试前的来源路径错误摘要，纠正到实际 data/pstring.h 后才运行测试；未改生产源迎合该路径错误。
