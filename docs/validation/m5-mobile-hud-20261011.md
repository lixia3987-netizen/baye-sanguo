# 原版移动横屏 HUD 首批验证

2026-10-11，范围为 `m.html` 的只读城市资料栏、原版 LCD 按比例布局及共享触控取消保护，完整移动 HD 保持 partial。

- 只在已验证原版 LIB 和当前原生地图等待状态展示城市、归属、年月、金钱、粮食、后备兵。菜单、报告及其它输入归属、换库或隐藏时清空资料；不写游戏世界或存档。
- 横屏预留固定 52px 资料栏，布局使用动态视口和安全区；竖屏保留旋转 LCD。共享触控记录 DOWN 时的尺寸／旋转，取消只发送一次，并使用最后已接受的游戏坐标。第二指落在 LCD 外也会取消，全部抬起后恢复。
- 新增 HUD 64 项及触控 24 项测试，接入 `npm run test:mobile` 和总测试。

本机真实原版 LIB SHA-256 为 `3bd20146084054163d045c90987c756a6a210664e78253cc56bc4a274727903e`。独立 Chrome／HTTP 服务／空白资料目录启动实际 WASM，通过公开 `sendKey` 输入接口完成标题、时期一和曹操开局；地图触控使用 CDP `Input.dispatchTouchEvent`，观察到的 DOM 触控全部为 trusted，没有修改原生数据或伪造引擎回调。

844×390、667×375 均核对资料栏与实际城市字段、52px 高度、LCD 边界与比例。触碰资料栏不发送原生触控；地图 DOWN→MOVE→CANCEL 使用最后 MOVE 坐标。空闲 resize 不发送 CANCEL，活动触控旋转为 DOWN→CANCEL 且无 UP；恢复横屏资料正常，进入真实城池菜单后字段清空、LCD 几何保持。日期、君主和 38 城归属／资源在这些操作前后相同。未捕获浏览器异常，请求无意外失败；运行来源零漂移。测试浏览器完整进程树已退出，私有服务已关闭，资料目录保留；用户 8080 服务仍由 PID 57860 运行并返回 HTTP 200。

复跑入口：`npm run test:mobile-runtime`，需要 Windows 本机 Chrome。完整回归使用仓库本地 clang 和 `node --test --test-reporter=tap --test-concurrency=4`，59 个测试文件、1512/1512 通过，0 失败／跳过。首次默认并发运行发生两个 V8 进程崩溃，两个模块独立重跑 41/41 通过；串行和 SPE 单独重跑另遇到旧异步图片就绪夹具的计时失败。最终限定并发整套通过，之前失败日志保留于本地 `build/mobile-precommit-*.log`，不将它们描述为初次通过。
