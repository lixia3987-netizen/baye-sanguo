## 投影与摄像机

- PROJ：`+proj=eqdc +lat_1=22 +lat_2=50 +lon_0=105 +ellps=WGS84`
- 源 SVG viewBox：`0 0 1920 1654`，**不裁海南 / 南海**
- 出荷地图：3840×3309（2× viewBox）
- SVG 仿射后再按比例落到出荷栅格：

```
x_svg =  3.842713776266e-04 * E + 1042.047274
y_svg = -3.871437493673e-04 * N + 2388.103445
x = x_svg / 1920 * 3840
y = y_svg / 1654 * 3309
```

开局摄像机框住西凉–襄平–建业–成都；拖动平移，夹在地图边界内。
屏上位置 = `(hdX - cameraX) * scale`。
