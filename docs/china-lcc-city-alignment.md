## 投影与裁切

- PROJ：`+proj=eqdc +lat_1=22 +lat_2=50 +lon_0=105 +ellps=WGS84`
- 源 SVG viewBox：`0 0 1920 1654`（栅格铺满画布）
- 出荷栅格：宽锁定 1920，自 SVG y=`145` 起取 1080 行（顶裁 145，底裁 429）
- 栅格仿射（eqdc 米 → 出荷 1920×1080）：

```
x =  3.842713776266e-04 * E + 1042.047274
y = -3.871437493673e-04 * N + 2243.103445
```

控制点为 SVG 湖面重心（伊塞克湖、青海湖、兴凯湖、巴尔喀什湖），残差 ≤ 6px。
16:9 竖裁切掉约 25°N 以南（海南、珠江口、台湾不在画布内）。
云南 / 零陵 / 桂阳 / 建宁 的投影落在画布南缘外，夹到 `hdY=1036` 以便点选。
