# HD 大地图当前规范（R08 / manifest v7）

本文前半部分是 2026-10-08 的当前规范。末尾的 P0–P4 探测与分期摘要是历史归档，不能作为当前授权、坐标、素材替换或输入实现依据。规则、存档、时期和城池指令由原 WASM 引擎负责；本批环境美术只改变表现层，不修改 LIB、原生城池 ID 或地理投影。

## 1. 当前范围与身份

HD 大地图使用 [manifest v7](../assets/hd-overworld/manifest.json)、完整中国 LCC 地形底图、山林装饰、道路、城标、城名与交互反馈。经典 LCD 可切回。城池菜单、战斗、帮助与小地图各有独立表现层和实际原生输入所有者，地图不能凭保留的 hook 或旧画面状态接管它们。

标准 LCC 定位仅在实际加载的 `dynLib` 摘要、manifest、地理表以及全部 38 城编号、名称、原生坐标同时匹配时启用。标准 SHA-256 为：

```text
3bd20146084054163d045c90987c756a6a210664e78253cc56bc4a274727903e
```

共享身份由 `BayeHdLibIdentity` 读取实际字节。首选文件路径、文件名和缓存路径都不能认证内容；相同正确字节可以来自任意路径。校验等待、未知 Mod、异常布局和陈旧异步结果保留原生 LCD 及玩家输入。身份代次变化时旧图片、地图数据与输入票据退役。详见 [实际 LIB 身份](hd-lib-identity.md)。

`City.Belong` 是 U16 归属值：0 表示无主；合法正数为 1-based 君主人物 ID，玩家归属为 `g_PlayerKing + 1`。255 等高编号正常按实际人物查询。65535、缺字段和非法值保持未知，不能把人物俘虏约定套在城市上，也不能把“无主”写成“无人”。势力色和图例只表达真实归属；堡城图片不自行携带势力身份。

## 2. 地图、投影与摄像机

| 项 | 当前值 |
|---|---|
| 设计画布 | 1920×1080；按实际窗口与 DPR 适配 |
| 完整世界底图 | 3840×4000 |
| Commons 源栅格 | 3840×3309，保留完整源图与海南 |
| 南侧延展 | 691 像素海面；不作为新增测绘来源 |
| 地理表 | `assets/hd-overworld/china-lcc-cities.json` 的既有 38 城锚点 |
| 投影 | `+proj=eqdc +lat_1=22 +lat_2=50 +lon_0=105 +ellps=WGS84` |
| 当前实际窗口验收范围 | 1920×1080 与 1280×720；移动真机另行验收 |

1920×1080 是可拖动摄像机窗口，不是“所有城永远一次塞进一屏”。开局焦点围绕西凉—襄平—建业—成都，拖动可覆盖全图与南侧海面。LCC 城标按 `(hdX - cameraX) * scale`、`(hdY - cameraY) * scale` 绘制；原生 `g_CityPositions` 格坐标用于原引擎规则、格光标和入城对齐。两者不混用。

```text
scale ∈ [max(1920 / mapW, 1080 / mapH), 2.2]
cameraX ∈ [0, max(0, mapW - 1920 / scale)]
cameraY ∈ [0, max(0, mapH - 1080 / scale)]
```

拖动、松手和 scale 变化后硬夹紧。底图是完整 LCC 栅格加南侧海面，没有旧文档所说的 16:9 竖裁。本批不改变地理表的仿射、经纬度或城池锚点，详见 [GEOGRAPHY.md](../assets/hd-overworld/GEOGRAPHY.md) 与 [38 城地理对照](china-lcc-city-alignment.md)。

原生 `C_MAP` 是按引擎地图宽度排列的 1-based 城号表；`CITYMAP_TILE` 按格位置选择 16×16 图片槽。它们不提供可直接仿射成 LCC 的山林河分类。战场 terrain 枚举也不能用于主图地理推断。

## 3. manifest v7 素材与绘制

绘制顺序为完整底图 → 环境装饰 → 低调道路/过河标记 → 城标/归属环 → 城名 → 悬停、选中与入城反馈。小地图共用已授权底图与环境合成，不改变真实 SEARCH 消费与地图输入所有者。

| 层 | 原图与实际像素 | 明确世界范围/实例 | 绘制 opacity |
|---|---|---|---:|
| 底图 | `terrain/base_plains.jpg`，3840×4000 | 完整世界矩形 | 1 |
| 河流 | `terrain/overlay_rivers.png`，1920×1655 | `[0,0,3840,3309]` | 0.12 |
| 山峦 | `terrain/mountain-cluster-v1.png`，1254×1254 RGBA | 源栅格内 10 个手工实例 | 0.66 |
| 森林 | `terrain/forest-cluster-v1.png`，1254×1254 RGBA | 源栅格内 14 个手工实例 | 0.62 |
| 城池 | `cities/fortified-city-v1.png`，1254×1254 RGBA | 既有城池锚点；常态屏幕盒 56px，悬停 60px，选中/入城基础盒 64px | 保留原 alpha |

环境描述以 `coordinateSystem: china-lcc-raster-padded-v1`、既有地理 `source`、`mapSize: [3840,4000]` 与 `rasterSize: [3840,3309]` 共同限定。河流原图的高度确为 1655；按它的真实像素尺寸映射到世界高度 3309，不能假定与底图同范围后拉到 4000。

每个山林实例有独立 `rect: [x,y,w,h]`。纯绘制模块先求世界范围、实例与视口的交集，源图片取样始终相对于完整未裁切实例；随后使用与底图一致的摄像机变换。3309 以南不延伸河流或山林。绘制使用显式 opacity 与 `source-over`，保存并恢复 Canvas 状态；缺文件、错误尺寸和坏的可选层独立跳过，不能破坏已授权城池地图。

山林实例是视觉装饰，既不是原生地形类型、移动代价或战斗效果，也不是古代生态分布和精确地质边界。manifest 的海南与南侧海面区域框只供人工源图与摄像机覆盖检查。它们不是测绘数据。

三张新素材分别用一次内置 imagegen 生成，透明 PNG 原样复制，未经裁切、缩放或 alpha 清理。完整提示词、原始生成路径、SHA-256、实际 alpha 与预览检查在 [GENERATED-ART.md](../assets/hd-overworld/GENERATED-ART.md)。多数主体像素 alpha 251–253，外围少量 alpha-1 噪点也保留；小尺寸可读性必须看实际绘制证据，不能由全分辨率生成成功直接推定。

旧 `overlay_mountains.png`、`overlay_forest.png` 的 8×8 全透明占位保留，但不在当前绘制清单。旧 `marker_*.png` 和 `cursor*.png` 保留供历史追溯；当前城标为新堡城，系统指针及程序描边承担反馈。新增版本素材与路径、真实尺寸、范围、来源元数据一起审查，旧“直接同名覆盖”不是当前素材交付要求。

## 4. 装饰道路、城市与原生输入

LCC 道路来自地理近邻展示图；原生格邻接可单独记录为调试数据。两者都不是 `SearchRoad` 或出征目标表。道路统一低调虚线，选城不增加可达边、金色路线或邻城可达环。过河标记只是曲线中点水体取样的程序装饰，`roads/pass.png` 不表示真实关隘、通行权或战斗加成。边数与标记数以当前运行快照为准，历史 67/5 等数字不再约束实现。

城标的归属、名称、年月来自实际引擎数据。新堡城供无主、己方和他方共用，环与图例表达势力；悬停、选中、短暂入城闪保持在原锚点上，不用素材位置推断输入目标。

生产桥接可用时，地图阶段依据当前 native menu、march、report、fight 等实际所有者判断。新开局、读档和 `didShowMainMap` 只唤醒只读同步，不凭 hook 名称强制变成 map。有城市归属、`g_PIdx` 像战役或保留的旧 phase，都不足以授权当前地图输入。旧桥兼容探测的启发式不能替代生产桥协议或实际 LIB 校验。

玩家点击己方城后，按真实原生格与 `g_hdMapCity` 对齐，再在实际地图等待中确认原生城号并进入原菜单。LCC 像素不是格走目标；不直接写原生游戏状态。点击他方或无主城只作选择和提示，不发送入城键。返回城池菜单走一次真实 EXIT，不能由菜单关闭 hook 再发送第二次。在实际地图等待中的空白点击、平移、装饰绘制、模式切换和隐藏页休眠不产生原生输入。小地图或其它所有者活动时，地图的旧 pointer 和确认票据不能复用。

## 5. 回退、检查与来源

经典 LCD 始终保留。未知 LIB、校验等待、未匹配城池布局、其它输入所有者、经典模式和隐藏页都停止当前 HD 地图的绘制/命中；重新显示须按当前身份和输入状态重新授权。可选环境层缺失可跳过，核心布局身份失败则回到真实 LCD。

实现与验收范围：

| `js/hd-overworld-layers.js` | 无引擎/DOM/计时器依赖的世界与源像素裁切 |

| `scripts/test-hd-overworld-environment.mjs` | 实际 manifest/素材尺寸、主图与小地图接线、回退/隐藏/身份退役 |

本次文档同步记录当前清单和契约，不把尚未运行的 R08 全流程、移动真机或其它验收写为已通过。素材头/alpha 检查、单元测试与真实浏览器流程是不同证据，具体结果在对应日志和证据文档中记录。

## 6. 历史探测与分期归档（不再作为当前规范）

早期 P0–P4 记录用于说明实现如何演进。它们的当时测试、缺口和临时退路不能外推到当前 source，也不是新一轮通过证据。

| 历史阶段 | 当时范围 | 归档的临时结论/方案 | 当前替代 |
|---|---|---|---|
| P0 | 1080p 容器、经典/HD 切换、只读探测 | 几何占位；原生坐标 min–max 映射；用城归属与时期猜 phase；考虑直接写光标字段 | 实际 LIB + 全部 38 城匹配、LCC 地理表与当前原生输入所有者 |
| P1 | 城态、归属色、年月、点击入城 | 探测 `g_YearN/g_CityCrt` 等候选；把 `Belong 0xff` 当俘虏；按城计数猜玩家 +0/+1；马腾少量跨城核验 | `g_YearDate/g_MonthDate`、真实格光标与城号；U16 城归属、`g_PlayerKing + 1`；完整流程按当前证据验收 |
| P2 | 道路、关隘、河层 | Chebyshev≤1 的 67 边、5 个过河标记；“LCC 竖裁”；同范围 overlay；山 overlay 试判关隘 | 完整源栅格与南侧海面；河1920×1655→世界3840×3309；地理近邻虚线与程序过河装饰 |
| P3 | 悬停、选中、短暂入城反馈 | 用选城/猜焦点在已有路上做金色“可达邻接”；允许菜单阶段继续点其它城 | 反馈不赋予道路可达语义；当前所有者、按键收据与输入票据决定点击处理 |
| P4 | 预备用户素材清单 | marker四图、8×8空山林、可选tileset、允许直接同名覆盖、缺项统一几何占位 | manifest v7 明确尺寸/世界范围/实例；新原图独立版本；可选装饰跳过与核心身份LCD回退分别处理 |

仍有价值的历史观察是：原生格坐标与 LCC 世界像素不同；方向键改变 `g_CityPos.setx/sety`；ENTER 所认城号由真实 `ShowCityMap/GetCitySet` 决定；年月为 `g_YearDate/g_MonthDate`。这些已融入当前协议，旧“没有城号”“一屏全图”“先按图像猜地图”“地图路径即身份”和“装饰关隘就是玩法”均不恢复为约束。

早期“当前提交只定规格、不要求美术”“不改 WASM”的分期描述只解释当时范围。后续桥接已有只读原生协议，城池/战斗/帮助各轨道也已经推进；本批 R08 只新增环境美术和表现接线，不重新限制已获授权的其它 HD 工作。
